OBSERVACIONES
-------------
1. La configuracion Compose es valida estaticamente.
2. El backup diario usa postgres:16-alpine y conserva un unico archivo:
   database/backups/netmo-latest.dump
3. El backup anterior solo se reemplaza despues de validar el nuevo.
4. Debe verificarse en un entorno Docker real que el usuario del contenedor
   pueda escribir en el bind mount ./backups.
5. Los backups y postgres-data estan en el mismo dispositivo; se recomienda
   copiar el dump a almacenamiento externo.
6. backend/Dockerfile no usa package-lock.json, por lo que npm install no queda
   completamente reproducible entre builds.

CONCLUSION
----------
Las validaciones estaticas y las pruebas aisladas del script fueron satisfactorias.
La validacion completa de PostgreSQL, restauracion y permisos Docker requiere
un entorno donde pueda ejecutarse Docker con las imagenes correspondientes.

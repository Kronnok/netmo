NETMO - CAMBIOS Y PLAN DEL PROYECTO

Estado actual (2026-09-22):
- index.html usa la API de Docker por defecto en http://localhost:3000.
- El login, el usuario autenticado, notebooks, reservas, prestamos, tickets y preferencias se cargan desde PostgreSQL mediante la API.
- El modo demo queda disponible solo si se define window.NETMO_API_URL = null antes del script de la pagina.
- La interfaz se sirve con un servidor estatico en http://localhost:5500.

Cambios recientes:
- Se agrego package-lock.json y el backend se construye con npm ci.
- PostgreSQL se ejecuta con un volumen nombrado y el puerto solo se publica mediante docker-compose.dev.yml.
- Las contrasenas seed se reciben por variables de entorno durante la inicializacion de un volumen nuevo.
- El servicio de backup valida dumps, reintenta conexiones, recupera locks abandonados y conserva hasta 30 copias fechadas.
- Se corrigio la cancelacion de reservas y se parametrizo CORS.
- La documentacion operativa esta en database/README.md.

Hallazgos para corregir:
- Posible XSS por uso de innerHTML con datos ingresados.
- Falta de validación de disponibilidad y conflictos de horarios.
- Los lotes pueden aprobarse con menos equipos de los solicitados.
- Estadísticas iniciales inconsistentes con el inventario demo.
- Accesibilidad incompleta en modales y tablas.
- Diseño responsive mejorable en móviles.

Arquitectura futura:
- Hostear la base de datos en Supabase.
- Usar Supabase Auth para autenticación.
- Usar PostgreSQL para persistencia.
- Aplicar Row Level Security según el rol.
- Usar Edge Functions para operaciones sensibles.

Tablas iniciales:
- profiles
- notebooks
- reservations
- loans
- tickets
- late_returns
- audit_logs

Plan de migración:
1. Migrar usuarios a Supabase Auth y profiles.
2. Migrar notebooks a la base de datos.
3. Migrar reservas, préstamos y tickets.
4. Crear políticas RLS.
5. Conectar la interfaz con Supabase.
6. Separar modo demo y producción.
7. Mantener el control de acceso por rol al pasar a producción.

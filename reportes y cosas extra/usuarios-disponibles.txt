IMPORTANTE
----------

- Estas credenciales son solo para desarrollo y pruebas locales.
- No utilizar estas contrasenas en un entorno productivo.

- Si el volumen ya existia, modificar las variables NETMO_SEED_* no cambia las
  contrasenas de las cuentas existentes.

DATOS DE LA BASE DE DATOS
-------------------------

Las cuentas de la aplicacion utilizan estas variables del archivo
 database/.env o database/.env.example:

NETMO_SEED_STUDENT_PASSWORD=[configure in a private environment]
NETMO_SEED_TEACHER_PASSWORD=[configure in a private environment]
NETMO_SEED_NETWORK_TEACHER_PASSWORD=[configure in a private environment]
NETMO_SEED_ADMIN_PASSWORD=[configure in a private environment]

La contrasena de PostgreSQL es independiente de las contrasenas de login:

POSTGRES_DB=netmo
POSTGRES_USER=netmo
POSTGRES_PASSWORD=[configure in a private environment]

UBICACION DE LA FUENTE
----------------------

Los usuarios se definen en:

- database/seed.sql
- database/.env.example

La API almacena las contrasenas como hashes. Este documento contiene las
contrasenas de desarrollo porque esta destinado a pruebas locales.

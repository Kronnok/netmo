4. TEST PENDIENTE DE DOCKER
---------------------------

Este test debe realizarse en una computadora que tenga Docker instalado.

En PowerShell:

  $env:POSTGRES_PASSWORD="una-clave-segura"
  docker compose -f database/docker-compose.yml up -d --build

Luego se debe comprobar:

  http://localhost:3000/health

El resultado esperado es una respuesta JSON similar a:

  {"ok":true,"service":"netmo-api"}

Tambien se deben revisar los logs:

  docker compose -f database/docker-compose.yml logs backend
  docker compose -f database/docker-compose.yml logs postgres

Al finalizar las pruebas, los servicios pueden detenerse con:

  docker compose -f database/docker-compose.yml down

La prueba de Docker es necesaria porque valida la conexion real entre:

  Pagina web -> API Node.js -> PostgreSQL
